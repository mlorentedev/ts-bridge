# 2026-11-11

**A login state is not a connection state.** `host serve` read its control session from the
IPN bus and called anything but `Running` an outage (#559/#560). With the control plane
stopped for four minutes on the local mesh, the bus sent nothing and stayed `Running`, health
warnings stayed empty, and `/health/ready` answered 200 throughout (#565). `Running` means the
node is logged in, not that it can reach control. `ipnstate.Status.Self.Online` dropped within
3 s and came back 14 s after the restart, so readiness now also polls it. Before choosing a
liveness signal, break the dependency on purpose and watch which values move: the one the code
already used was the one that did not.

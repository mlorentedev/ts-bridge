# 2026-11-02

**A stacked PR is not CI-checked.** `ci.yml` filters `pull_request` to `master`, so a
PR based on a feature branch runs only hygiene and the PR-Agent review. Three
`misspell` lint errors survived four reviewed HOST-008 PRs and surfaced only when the
stack was retargeted to `master` (#560). Retarget, or push once against `master`,
before calling a stacked PR green.

**An inherit-only ACE is not harmless.** It skips the directory itself, but it is
exactly what the files created inside receive. A Windows key-store check must refuse
any allow grant to an untrusted SID, read and inherit-only ones included; only
CREATOR OWNER on an inherit-only ACE resolves to the creator (#556).

**A stub-based test cannot see its own wiring.** Every `host serve` command test
stubbed the `state_dir` and auth key guards, so replacing the shipped initializer
with a no-op left the suite green. Capture the package's initial value in a `_test.go`
variable and run one command test with it (#560).

**Write a file the way you will read it back.** `yaml.Marshal` writes a nil pointer
as `key: null`, which the host file loader rightly refuses as a key with no value.
`host init` loads the file it just wrote before reporting success; that read-back
caught the missing `omitempty` before any test did (#458).

**Regenerate a probe after the code moves.** A saved mutation patch whose context
changed stops applying, and `dotf pr reproduce` reports an error, not a verdict:
rebuild the patch on the current tree.

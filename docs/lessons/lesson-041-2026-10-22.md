# 2026-10-22

**A state that could not be read is not a state that is absent.** `host check`
on Linux read the firewall with `ufw status`, then `iptables -L`, and turned
any read error into "no rule". Without root both reads fail, so a converged
host reported `changed` and told the operator to run `host setup`, which
appends an `iptables` rule on every run (#454). Once #471 made a non-ok step
exit 2, that guess became an exit status scripts act on. A read must return
two things, what it found and whether it could look, and "could not look"
maps to `unverified` with a fix that names the missing privilege (#473).

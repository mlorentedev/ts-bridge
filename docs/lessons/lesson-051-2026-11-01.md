# 2026-11-01

**A check outcome is a promise about setup.** `host check` reports `changed`
where `host setup` would converge the state: a missing rule is `changed`, and
setup then appends it. Copies of setup's own rule, piled up before #477, are
drift that setup never removes, because it never deletes firewall rules. If they
were reported as `changed`, check would keep promising a fix that setup never
delivers, and setup would say `ok` forever. Drift that only a person can resolve
is `manual`, with the command in the fix (#480).

**Count the printed form, not the command line.** Setup runs `-A INPUT -p tcp
--dport N -j ACCEPT`, but `iptables -S` prints `-p tcp -m tcp --dport N -j
ACCEPT`. Match by fields against the printed form, derived from the command
setup runs, so the two cannot drift apart. Count only that exact shape: a scoped
allow beside it is the operator's hardening, not a copy.

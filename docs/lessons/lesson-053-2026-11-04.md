# 2026-11-04

**`tailscale up` does not set one pref.** It re-applies the node's whole pref set and
refuses when the node holds non-default prefs it was not given again. A Headscale
`--login-server` is one of those. So `host setup` running `tailscale up --unattended`
failed on exactly the hosts ADR-005 targets (#455, W1). To change a single pref, use
`tailscale set --<flag>`. `--unattended` maps to the pref `ForceDaemon`, which is what to
read before writing.

**When the read comes from an unstable interface, fail open toward the action.** The
only CLI that prints `ForceDaemon` is `tailscale debug prefs`, a debug subcommand with no
compatibility promise. The step therefore skips the write only on a positive parse of
`ForceDaemon: true`. Anything else runs the idempotent `set`. If the format drifts, the
cost is one redundant command and a `changed` where `ok` was due. The write is never
silently skipped.

# 2026-10-20

**Cross-compiling a platform proves it compiles, not that it behaves.**
`build-matrix` built `GOOS=darwin` on every PR, yet `go test ./...` failed on
every Mac: `TestLogDirForPlatform` asserted a lowercase `logs` segment that the
darwin layout (`~/Library/Logs/ts-bridge`) never contains. No job ran tests on
macOS, so the darwin branch had never executed under test (#447). Count a
platform as covered only where its tests run, not where it builds.

**Make the OS an input, not a global read.** A function that switches on
`runtime.GOOS` can only have the branch of the runner's own OS tested. Splitting
it into a thin wrapper (`LogDirForPlatform`, which reads `runtime.GOOS` and the
environment) and a pure core (`logDirFor(goos, home, appData)`) lets one Linux
runner cover every branch, with a single wiring test for the wrapper. The native
macOS job then confirms what only a real Mac can answer instead of being the
first and only test of each darwin branch.

# 2026-11-13

**A claim about a vendor's unit file is a claim about one release.** `socketIsModel` and ADR-017 §5
said `ssh.socket` `Conflicts=` with `ssh.service`, and used that to keep the service on a host whose
socket is disabled (Debian 12, Ubuntu 22.04 and earlier). Reading the packaging per release shows the
line is real for Debian 11 and Ubuntu 20.04 and 22.04, and absent from Debian 12 and 13 and from
Ubuntu 23.04 and later, where the socket is only `Before=` (and, on Ubuntu, `RequiredBy=`) the service.
Where nothing conflicts, enabling the socket beside an enabled service is allowed and leaves both
enabled, which is exactly the host an earlier ts-bridge release left behind and `host check` read as
`ok` (#777). Before writing a rule on what a distribution ships, fetch the unit for each release the
rule names (`git.launchpad.net/ubuntu/+source/openssh`, `sources.debian.org`), and word the comment
with the releases, not with "the socket".

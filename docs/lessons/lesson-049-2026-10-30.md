# 2026-10-30

**`yaml.Unmarshal` reads one document and drops the rest.** A host file with a
`---` separator loaded its first document and silently discarded every
declaration after it. `LoadFile` uses `yaml.NewDecoder` and fails when a second
`Decode` does not return `io.EOF` (#458).

**A struct decode is not a key check.** yaml.v3 skips unknown keys without
decoding their values, so an invalid merge under an unknown key loads cleanly.
Decoding into `map[string]any` resolves aliases and merge keys the way the
struct decode does. Walk that map for unknown keys and keys with no value, and
return its decode error. Omitted and `key:` (null) both decode to a nil
pointer, so presence has to be read from the map, not from the struct.

**`url.Parse` hides credentials and accepts any port.** `https:user:pw@host`
parses as opaque with `User == nil`, and the port is only checked for digits.
Check `u.User` first, then `Hostname()` and the port range, and never echo a
rejected URL: the value the check could not read may hold the credential.

**A flag default is a layer.** `host setup --firewall-rule` defaulted to
`Tailscale-RDP-Ingress`, so the flag always "won" and `TS_HOST_FIREWALL_RULE`
never applied. A flag that sits above env and file must default to empty and
keep its default in the help text; the default belongs to the bottom layer.

**A mutation that does not apply proves nothing.** A mutation check that wrote
the mutant through `[IO.File]` with a relative path edited a file under .NET's
own current directory, not PowerShell's, so every mutant "survived". Confirm
the replacement landed (or use absolute paths), and restore the original in a
`finally` so an interrupted run cannot leave a mutant in the tree.
